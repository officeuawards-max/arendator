# Картинки лендинга

Положите файлы с **точно такими именами**, и они сами встанут на место.
Пока файла нет, берётся фото, которое уже лежит на сервере aawards.ru (`data-alt-src` в `index.html`). Если нет и его, показывается аккуратная заглушка.

| Файл | Блок | Рекомендуемый размер |
|------|------|----------------------|
| `logo.svg` | Шапка сайта, логотип премии (белый) | SVG, высота ~34px |
| `hero.jpg` | 01 Шапка, фото «для шапки» | 2400×1400, JPG ~300–500 КБ |
| `about-1.jpg` | 02 О премии, большое фото | 1200×1000 |
| `about-2.jpg` | 02 О премии, второе фото | 1200×900 |
| `about-3.jpg` | 02 О премии, круглое фото | 600×600 |
| `gallery-1.jpg` … `gallery-6.jpg` | 08 Как проходит | 1200×900 (`gallery-3` вертикальное 900×1400, `gallery-5` широкое 1600×800) |
| `reviews/1.jpg` … `reviews/4.jpg` | 09 Отзывы, аватары | 160×160 |

## Логотипы компаний (блок 04), папка `logos/`

Монохромные SVG (белые или любые: в спокойном состоянии они обесцвечиваются, при наведении показывают свой цвет).

```
logos/esve.svg
logos/stone.svg
logos/level-group.svg
logos/lemana-pro.svg
logos/space1.svg
logos/forma.svg
logos/valtari.svg
logos/donstroy.svg
logos/mr.svg
```

Пока файла нет, вместо логотипа выводится название компании.

Видео для блока 08 берётся с сервера: `https://aawards.ru/videos/apply/aaw_apply_2025.mp4`. Если будет новое, замените ссылку в `index.html`.
